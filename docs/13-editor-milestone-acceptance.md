# Editor milestone acceptance

The path, rigging, animation/interaction and compatible-export milestones requested on 2026-10-08 are implemented and verified for the first declared authoring subset. [Research before implementation](12-editor-milestone-research.md) records the primary-source findings. [Studio's guide](../packages/studio/README.md) lists controls and the project schema.

| Milestone                 | Implemented                                                                                                                                                                                            | Evidence                                                                                                                                                                                                   |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Editable paths            | Cubic anchors/detached handles, numeric and pointer edits, curve-preserving subdivision, point deletion, closure, solid fill, rectangle conversion.                                                    | Analytic subdivision samples; browser coordinate editing, split/delete, drag/cancel/undo; official-runtime curved renders.                                                                                 |
| Rigging                   | Root/child chains, parent-tip attachment, bind matrices, independent per-control normalized weights, bind/unbind and deformation.                                                                      | Nonidentity 45° bind matrix; animated child rotation, root translation/length and independently weighted handle; browser bone/weight authoring.                                                            |

| Rive-compatible export    | Schema-derived binary writer and namespace mappings, origins and packed weights, explicit default restoration, unsupported-content diagnostics.                                                        | Both official web runtimes load actual browser-downloaded files; pixel comparison at selected frames; binary codec independently parses and exactly rewrites both output fixtures.                         |

`npm run test:editor` passes 20 model/compiler tests, the established foundation browser workflow, and the new complete authoring browser workflow. `npm test` passes 22 existing binary/mesh tests. `npm run validate:editor` compares 20 scenes/poses/interaction outcomes on each official runtime (Canvas2D and WebGL2, version 2.44.0). Six checks per backend use the file downloaded from actual UI authoring, rather than invoking the compiler directly.

The pixel oracle renders Studio's independently evaluated pose on a Canvas2D surface, then compares every RGBA channel with the official runtime at the same fit/frame. It includes translucent overlapping shapes to detect draw-order mistakes. The maximum mean absolute channel difference was below 0.23 on a 0–255 scale; the permitted bound is 2.5, and coverage must differ by fewer than 350 pixels on a 256-square surface. Small backend edge differences are expected. These selected scenes establish subset correctness, not universal rendering equivalence. Results are committed as [Canvas2D](../research/results/editor-authoring-canvas.json) and [WebGL2](../research/results/editor-authoring-webgl2.json).

The WebGL2 checks run on this cloud's software graphics implementation. No hardware performance, mobile usability or physical-device rendering claim is made. The user's device audit remains deferred, and the four earlier controlled equivalent Rive Editor scenes remain pending in the runtime audit.

## Export and persistence guarantees

Supported v1 projects validate before migration to v2. Unsupported versions, unknown fields, invalid geometry, broken references and typed-condition errors are rejected. Saves retain path IDs, bind data, animations, graph records and embedded assets; cryptographic content checks remain at the persistence boundary. Transactions reject partial mutations and restore deleted tracks/listeners on undo.

Export includes solid rectangles/cubic paths, TRS groups/bone chains, up to four influences per control, typed linear/hold/cubic property keys, one-layer conditional machines and click listeners. All attached assets, shear/singular node transforms and values outside float32 range fail with a diagnostic. Locks/hidden state are authoring controls and are not exported as runtime visibility. The source map connects stable project IDs to artboard component, animation and machine namespaces.

Missing animation tracks in the artboard's animated-property union become constant default keys at export. This explicitly reconciles Rive's retained-property application with Studio's authored-base pose evaluation. Source data is preserved exactly; this compiler decision is recorded rather than passed off as original Rive Editor behavior.

## Scope left outside these four milestones

Freehand/pen gestures, multiselection, snapping, resizable panels, graph dragging, gradients, clip/feather authoring, meshes/IK, text/raster rendering, blend trees and transition mixing, nested machines, RML authoring, semantic `.riv` import and large-project optimization are subsequent work. SOBO remains an inspection/runtime workload; it is not silently imported as an editable project. Comparative research informs the UI; representative user testing is still needed to establish usability.
