# Gradient and skinned strokes

21 October 2026. This extends the retained-centerline contract with shape-local linear/radial stroke paint and weighted deformation. The [research ledger](../research/software-closure/sources.json) records the pinned Rive Stroke, LinearGradient and skin implementations. Rive's Stroke chooses the shape's local path when transforms affect its width; its paint mutator supplies either color or gradient. Evir follows that space relationship and validates it against official Rive 2.44 pixels.

Select a stroked shape and choose **Properties → Edit stroke paint**. Choose Solid, Linear gradient or Radial gradient, set endpoints and stops, then Apply. Cancel preserves the source. **Edit stroke** still controls width, caps/joins, dashes and trim and retains the selected paint. Animate exposes gradient endpoint, stop position and color properties. Changing the frame retains the selected key property/easing. Remove incompatible color keys before changing a solid stroke to a gradient; the ordinary source validator rejects conversions that invalidate existing gradient tracks.

Bind a path with stroke paint using **Bind skin bones…**. Its weighted anchors and handles deform the centerline, while stroke width continues to follow the shape transform. The renderer reconstructs the deformed path in shape-local paint space before applying stroke style and effects. Native export emits the same skin/contour records as filled paths and the corresponding gradient under Stroke. Import retains both paint and bindings. Stroke bounds now include the deformed envelope and every contour; large bounds reductions avoid spread-argument limits.

`geometry.stroke.color` accepts the same solid hex or gradient object as a fill. This reuses the existing field rather than adding an unused fallback color. Gradient keys are `stroke.paint.startX`, `startY`, `endX`, `endY`, and `stroke.paint.stop.N.position/color`. `stroke.color` is available only for solid paint. Existing solid exports retain their bytes. Shared commands can author these validated geometries and key properties through the existing `create_node`, `update_node` and `set_key` operations.

Nocturne's curved owl outline demonstrates gradient stroke paint. The [original skinned fixtures](../tests/fixtures/gradient-strokes.mjs) exercise solid/linear/radial paint, bone animation, nonuniform shape scaling and editable reimport. [Responsive browser evidence](../research/results/software-closure/stroke-paints/) contains actual Studio source/native downloads and paint sheets at four viewport sizes. [The native report](../research/results/software-closure/compounds/native.json) includes these fixtures, their hashes and both official backends. It currently records 108 comparisons per backend, including the compound, live-shape and smooth-connection cases.

The native image thresholds remain MAE < 2.5 and absolute coverage difference < 350 pixels at 256×256, with visible geometry required. Dash/trim output remains bounded polyline approximation. Stroke feathering, stroke-position variants and arbitrary Editor-file conversion are separate contracts. Cloud automation does not establish physical performance or human accessibility. The sheet cancellation regression also now guards immediately on closed/disconnected state, before the browser's asynchronous close event.
