# Brand asset provenance

The user supplied the EVIR wordmark presentation and white/black E icons in chat. Their later instruction permits crops, proportional resizing, format conversion and background removal while preserving the supplied appearance.

These PNGs are image-assisted preparations from those supplied visual references, rather than byte-identical original uploads (the originals were not exposed as workspace files). They retain the white-on-dark wordmark and detached-bar E motif; the user owns the source branding. No license is inferred for the artwork.

The first transparent-background attempt introduced artifacts and was rejected; it is not shipped. The two clean opaque preparations are used in the header and browser icon. The display wordmark and 64-pixel favicon are proportional ImageMagick resizes of the full-resolution preparations. CSS preserves the header aspect ratio. No CSS filter, recoloring, synthetic SVG tracing, animation, or replacement letterform is applied. Full-resolution preparations are retained so they can be compared with the chat originals and replaced by exact original files when accessible.
