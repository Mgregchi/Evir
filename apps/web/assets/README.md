# Public showcase provenance

`milo-poster.png`, `orbit-poster.png`, `bloom-poster.png`, `tempo-poster.png` and `signal-poster.png` are browser captures of independently authored Evir projects in `examples/`. Their editable source uses Studio's project schema; their `.riv` files are built by Evir's existing subset compiler. No artwork from the supplied third-party Rive files is used here.

`studio-overview.png`, `studio-paths.png`, `studio-animation.png` and `studio-interact.png` are real 1440×900 screenshots captured from Evir Studio with the Milo project open. They are not interface mockups. Reproduce with `npm run web:assets` in the repository environment.

Both builds copy the existing Evir wordmark and favicon unchanged from `assets/brand/`. See [brand provenance](../../../assets/brand/README.md); no logo recoloring, replacement letterforms or remix is added by this site.

Example artwork and website source are original project contributions. Existing brand provenance is separate from the code's MIT license. Uploaded research files remain outside the public distribution.

`evir-showcase.jpg` is an AI-generated story illustration, not an editor screenshot. It references the independently authored Milo poster: Bézier outlines → motion → an interactive hello. The original Evir wordmark/icon were not supplied to generation or altered. The original generated 1730×909 artwork was proportionally resized and center-cropped to 1200×630 JPEG (84,258 bytes); SHA-256 `d0d91f066db9cc869ad7815701245dcfff7dc4ec083709d936f825bff9393cab`. It is the Open Graph/Twitter image when `SITE_URL` is configured. Actual Studio screenshots remain separately labeled.
