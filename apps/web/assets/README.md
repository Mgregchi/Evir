# Web showcase assets

Original gallery artwork is project work under the repository MIT license. Supplied brand artwork retains its [separate provenance](../../../assets/brand/README.md). Privately uploaded research scenes and stock reference images are not gallery assets. Generate editable examples with `node apps/web/generate-examples.mjs`; capture actual posters with `node tools/capture_site_assets.cjs`.

[Gallery research and acceptance](../../../docs/23-growing-showcase-gallery.md) records each study’s supported features. Posters are actual Canvas renders; each study includes editable source and an Evir-compiled `.riv`.

Wisp’s organic outlines are generated sampled loops fitted with Studio’s freehand algorithm, not captured human handwriting. Its poster is a real Canvas render; all point IDs in its source/export are deterministic.

`measure-poster.png` is a real Canvas capture of the original Measure composition in `examples/measure.evir-project`. `measure.riv` is its Evir-compiled native export. `measure.guides.json` is a separate Studio guide preset; guides are excluded from scene/native exports. The three cards and Balance loop contain no supplied third-party artwork.

`sprig-poster.png` is a real Canvas capture of the original Sprig plant. `sprig.evir-project` / `.riv` contain the completed six-point leaf and Breeze loop; `sprig-start.evir-project` / `.riv` retain its three-point open seed. `sprig.continuation.json` is a readable numeric point recipe, not an importer or runtime feature. All artwork is original project work; no uploaded research scene is redistributed.

`loom-poster.png` is an actual Canvas capture of the original Loom woven patches and spindle. `loom.evir-project` and `loom.riv` carry the editable geometry and Weave loop; `loom.guides.json` holds separate version-2 row/column guide preferences. All artwork is original MIT project work, with no supplied research scene or altered brand artwork.

`ribbon-poster.png` is an actual Canvas capture of the original Ribbon study. `ribbon.evir-project` and `ribbon.riv` contain two pressure-varying filled outlines, a constant-width thread and the Float loop. Pressure samples are generated rather than recorded from a person or physical pen. Outline construction uses the pinned MIT-licensed perfect-freehand package, followed by Evir's existing cubic fitter; its license is distributed with Studio. All sample artwork is original project work.

`trace-poster.png` is an actual Evir Canvas render of the original editable Trace courier/postcard study. Its source and `.riv` live in `examples/trace.*`, generated by `../stroke-scene.mjs`. The original artwork is MIT licensed; no third-party reference illustration is embedded.
`outing-poster.png`, `examples/outing.*` and `examples/outing-start.*` are original MIT Evir vector artwork from `../join-scene.mjs`: a curved fox holding a kite. The completed source is generated by joining the two starting string paths with shared authoring operations; the poster is an actual Evir Canvas capture. `outing.joining.json` is a readable recipe. No supplied stock imagery or modified brand artwork is used.


`gust-poster.png` is an actual Canvas capture of the original Gust bird/scarf study generated by `../weight-scene.mjs`. `examples/gust.evir-project` and `.riv` include three-bone path/control weights and a ten-vertex mesh with a tiny generated original weave PNG. The artwork is original MIT project work; no supplied reference/corpus artwork or modified brand image is included.

Pocket garden is original MIT vector artwork generated with Evir’s own shape factory; its poster is an actual Canvas capture. `first-bounce.*` is the exact completed beginner lesson. `learn-shapes.png` and `learn-bounce.png` are actual Studio screenshots produced by `tests/editor/shapes-browser.cjs`; no external artwork or supplied brand alteration is involved.

`lumen-poster.png` is an actual Canvas capture of the original Lumen firefly. The editable source and `.riv` in `examples/lumen.*` contain 48 named vector/group nodes, sparse Rest/Joy/Courage timelines and an ordered direct state. The artwork is MIT project work from `../direct-scene.mjs`; no supplied reference imagery or changed brand artwork is embedded.

`nocturne-poster.png` is an actual Evir Canvas capture of the original Nocturne owl. `compound-scene.mjs` creates curved body/ear unions, real eye cutouts and a subtracted crescent, with separate wing/group motion. Editable source, compatible export and starting shapes are supplied under the project MIT license; no external artwork or changed brand image is included.

`kelp-poster.png` is an actual Canvas capture of the original Kelp sea creature from `../kelp-scene.mjs`. Editable source and native export contain a four-bone IK chain, separately weighted curve handles, a gradient centerline stroke and a looping independent target. MIT project artwork; no external imagery or modified brand artwork is included.
