# Public showcase provenance

`milo-poster.png` and `orbit-poster.png` are browser captures of independently authored Evir projects in `examples/`. Their editable source uses Studio's project schema; their `.riv` files are built by Evir's existing subset compiler. No artwork from the supplied third-party Rive files is used here.

`studio-overview.png`, `studio-paths.png`, `studio-animation.png` and `studio-interact.png` are real 1440×900 screenshots captured from Evir Studio with the Milo project open. They are not interface mockups. Reproduce with `npm run site:assets` in the repository environment.

Both builds copy the existing Evir wordmark and favicon unchanged from `assets/brand/`. See [brand provenance](../../../assets/brand/README.md); no logo recoloring, replacement letterforms or remix is added by this site.

Example artwork and website source are original project contributions. Existing brand provenance is separate from the code's MIT license. Uploaded research files remain outside the public distribution.
