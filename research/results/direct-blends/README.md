# Direct blends and Lumen validation

[Contracts, research and workflow](../../../docs/45-direct-blends-and-lumen.md) explain the shipped one-state direct subset and the remaining graph/import limits. Application commit `6b37928` implements ordered fixed/input weights, sparse native scopes, Studio rows, read-only repaint, Lumen and the landscape rail name. `39a7734` guards malformed machine records; full runtime tests/build and the Studio workflows were checked after that guard. See [the ledger](validation.json) for actual command times, exit codes and the earlier failed attempts. Logs are in `logs/`.

`browser.json` records four independent browser contexts (320/390 portrait, 844×390 landscape, 1440 desktop), draft errors/cancellation, row actions/focus, history, typed test inputs, actual export/recovery and automated accessibility. `direct-sheet-*` and `direct-stage-*` are actual Studio screenshots. `studio-direct.*` are the real edited project and downloaded export, not a reconstructed substitute. Test values and sheet state do not enter saved source.

`native.json` records 360 raw RGBA comparisons: 180 per official Rive 2.44 Canvas/WebGL2 backend. Seven source/native fixture pairs cover independent input and omitted-default fixed rows, Evir export, color, accumulated rotations, original Lumen and the Studio edit. Each has explicit clocks/inputs, nonempty coverage and preset MAE <2.5 / coverage difference <350. Zero-weight clocks are activated later, and inputs are cleared after a changed pose. The harness uses pinned private runtime stepping solely for deterministic research. `import.json` checks both complete Lumen native files through editable import, numeric mixed poses, re-export and import again.

`assets.json` / `regeneration.log` record 70 reproducible generated files and byte preservation for all 101 earlier published assets. Gallery/public/experience reports record the 29-study site, keyboard index disclosure, touch-sized feeling controls, download round trips and existing scheduling/accessibility checks. `2b9380e` corrects a fixed initial-visibility test assumption; `c0127fc` adds the researched compact index. Full web checks run after these changes. Previous feature evidence is kept historical rather than overwritten with this run.

These checks use cloud software rendering. They do not establish physical-device performance, screen-reader usability, moderated-user evidence, universal Editor-file import or hosted services. Physical tests remain postponed; backend remains deferred.
