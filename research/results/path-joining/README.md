# Path-joining evidence

See [the shared contract and Studio workflow](../../../docs/44-path-joining-and-outing.md). This increment starts from main `8efe5d2`; contour-import/Tide and graphical skin-weight/Gust product work remain in separate PRs #36 and #37. Outing is original project artwork. Existing brand artwork and privately supplied research scenes are untouched.

`browser.json` records real Studio workflows at 320×844, 390×844, 844×390 and 1440×900. Selectors review all endpoint pairings without source mutation. Both Bridge and Merge, undo/redo, source recovery, actual native downloads, explicit multiple selection and incompatible paint are checked. Automated WCAG checks run in the sheet; actions must remain reachable in short landscape. The initial heading receives focus, Cancel returns to the opener, and successful Apply closes the compact Properties drawer before returning focus to the stage.

Stale-selection testing deliberately injects a programmatic background selection event. It does not claim that users can click through a modal, or that Live tools remain paired after closing. A detached Apply callback is also invoked after Cancel to verify that its aborted controller cannot edit the source.

`studio-joined.evir-project`/`.riv` and `studio-merged.evir-project`/`.riv` are actual UI downloads/snapshots. They retain the original animation and assets. The focused native oracle checks these two sources alongside the published completed and starting Outing scenes. Each also has a separate animation-free rest export, because the official high-level runtime initializes its first clip even when paused. The eight `*-oracle.evir-project`/`.riv` pairs and `native.json` record source/native hashes.

Five animation frames plus separate rest poses produce 24 comparisons per official Canvas/WebGL2 backend, 48 total. Preset gates are MAE < 2.5 over raw RGBA byte values, coverage difference < 350, and more than 10,000 covered pixels in both images. Empty output cannot pass. Lossless raw-byte transport avoids Playwright validating a separate protocol object for every pixel; hashes, pixel calculations and thresholds are unchanged.

`validation.json` identifies tested commits, command outcomes, unit/browser counts, log hashes, source/export hashes and the current gallery/native/experience reports copied into this scope. `logs/` contains completed command logs. Older generated research snapshots are restored after current reports are copied here. The incomplete first Studio run is recorded separately: review found redundant full source copies per preview, so the affected checks restarted with one snapshot and no duplicate pre-Apply plan. A final focused check verifies the completion toast's success classification; it changes no runtime geometry.

The first public-web attempt failed while viewport emulation still exposed desktop media-rule geometry at 390px. A diagnostic confirmed that the settled mobile rules fit. The test now allows up to two seconds for three consecutive zero-overflow frames; its original strict assertion and failure diagnostics remain. No production site CSS was changed to hide overflow. A focused recovery attempt also reloaded before the existing 250 ms debounce completed; the corrected check waits for **Saved in this browser**, which indicates a committed IndexedDB transaction. Both failed attempts are recorded separately from completed passes.

The final UI review adds circle/square endpoint cues with visible and accessible labels. Both Bridge and Merge native files are now downloaded through the actual Export action, then checked against the compiler. Their source and export hashes still match the completed native-oracle fixtures.

Evidence uses cloud Chromium with ANGLE/SwiftShader software graphics. Synthetic touch/keyboard/lifecycle and automated accessibility checks do not establish physical GPU/mobile performance, human usability or screen-reader certification. Physical tests remain postponed and hosted backend remains deferred. Ordinary joins are bounded to compatible adjacent open unskinned sibling paths; automatic smoothing, gesture concatenation and gradient/skinned joins remain open.
