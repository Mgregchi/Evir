Twenty-five source/native fixture pairs include every preset, boundary variants, the finished lesson, the actual Studio lesson and garden. `rgba-transport.json` records a fresh two-backend playback rerun after replacing expensive per-pixel number-array protocol transfer in three older validators. All 41 Canvas clock, pixel and coverage measurements exactly match the original transfer; assertions/thresholds were retained and byte-length guards added. Thresholds for new shape comparisons remain MAE <2.5, coverage difference <350 and nonempty geometry. `assets.json` reproduces both new source/native pairs using the exact generator helper and compares all 101 older published assets byte-for-byte with base main.

Scoped public/gallery/experience reports preserve this run without overwriting historical feature evidence. Cloud checks do not establish physical-device performance, beginner usability or screen-reader behavior. Physical tests stay postponed and backend remains deferred.
